# ForexHub

ForexHub is a risk-controlled forex market monitoring and paper-trading application.

## Phase 1
- Market watchlist
- BUY / SELL / HOLD signal dashboard
- Paper trading with virtual balance
- Stop-loss and take-profit
- Risk-per-trade controls
- Open positions and trade history
- P&L dashboard
- Supabase-backed persistence

> Paper trading only. Real-money broker execution is intentionally disabled during testing.
